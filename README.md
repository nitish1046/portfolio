## 🚀 Key Highlights & Features

- **🌐 Interactive 3D World (Three.js):** Real-time interactive geometric wireframe core with rotating cyber torus knot, orbital rings, and mouse-reactive 3D particle data points.
- **💎 Glassmorphism UI:** Dark-themed aesthetic (`#04060a`) with electric cyan (`#00d2ff`) and purple (`#a855f7`) accents, digital grid overlays, and ambient gradient meshes.
- **🔊 Subtle UI Audio Synthesizer:** Pure Web Audio API synthesized sound feedback for buttons, cards, and modal interactions with one-click mute/unmute control.
- **⚡ Technical Arsenal:** Categorized skills overview across C++, C, Python, DSA, Object-Oriented Programming, and Modern Web Standards with 3D tilt effects and zero fake percentage metrics.
- **📦 Things I've Built (Featured Projects):**
  - **SurplusToShelter:** Food-rescue platform connecting donors with shelters and volunteer drivers (Flask, SQLite, JS, HTML/CSS).
  - **Smart EV Charging Management System:** High-performance C++ station & slot management system using OOP, STL vectors, and file handling.
  - **Waste Segregation Monitoring System:** Environmental urban monitoring logic and telemetry.
- **📄 Interactive Resume Viewer:** In-browser resume preview modal with direct download of `/resume.pdf` and printable format.
- **✨ Beyond Code:** Interactive interest cards highlighting Cricket, Music, Photography, Traveling, Gaming, Dance, and Fitness.
- **📬 Transmission Portal (Contact):** Validated contact form that generates direct transmission links to `nitishkumar741188@gmail.com` with celebratory confetti feedback.
- **📱 Fully Responsive & Accessible:** Fluid layouts optimized for mobile, tablet, and ultra-wide displays with custom desktop cursor and `prefers-reduced-motion` compliance.

## 💻 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/nitish1046/nitish-x-portfolio.git
   cd nitish-x-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start local development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```
